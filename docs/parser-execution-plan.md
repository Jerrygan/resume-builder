## P1 · 本轮执行（纯离线）

**目标**：把 OpenResume 的“行合并 + 标题判定 + 特征打分 + 间距子段”思路中文化落地。

### 任务拆解
- [x] T1.1 行合并：相邻片段间距 < 平均字宽时拼接（PDF 路径）
- [x] T1.2 标题打分：实现 §5.4 打分表；替换当前“关键词子串”判定
- [x] T1.3 字段特征打分：姓名 / 邮箱 / 电话 / 学校 / 学历 / 日期 / 公司 / 职位
- [x] T1.4 子段切分：间距 > 行距×1.4 或日期区间行 → 新子段
- [x] T1.5 与条目分组整合：工作/项目/教育渲染为结构化条目（时间/单位/职位 + 要点）
- [x] T1.6 回归：脱敏通用样本（单栏 Word + 双栏/图文 PDF 各 1 份）

### 实现位置
- `index.html` 的 `parsePdf`（补 `x/y/size`，已具备）
- `toModel` / `layoutSections` / `matchHeading` / `groupEntries`
- 新增 `scoreHeading(line)`、`extractFields(section)`、`rowMerge(items)`

### 验收标准（P1）
1. 通用 Word 样本：`教育背景/工作经验/项目经验/专业技能/自我评价` 全部识别；工作/项目按时间分条。
2. 两条以上日期行的板块，渲染为多条 `.item`（含要点），不再全平铺。
3. 短行如“项目B 2023.03-至今”不再被误判为标题（含数字一律不算）。
4. 无个人信息写入仓库；回归脚本输出**脱敏统计**。
5. 不改坏 P0 行为（docx/PDF/头像/编辑/导出）。

### 回归方法（脱敏）
- 用脚本生成**通用样本**（示例姓名/某某大学/某某公司）做 Word 测试；
- 用 Node + Edge CDP 驱动 `window.__rb.handleFile`，只读取脱敏统计（板块类别/数量、姓名长度、照片尺寸）；
- 不打印简历正文；临时文件测试后删除。

## 风险与取舍
- 纯前端 + 单文件 + 离线，与“全量 OCR/视觉”体积冲突 → OCR 只做可选懒加载。
- 设计版/PSD 导出的**整页图片型 PDF**，文本层无标题 → 只能版面兜底或 OCR/后端。
- 特征打分需持续用脱敏语料回归，避免“修 A 坏 B”。
