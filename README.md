# 网页简历编辑器 · Resume Builder

一个**纯前端、单文件**的网页简历编辑器：上传 PDF / Word 一键生成**可编辑**的网页简历，并支持板块与要点的增删拖拽、标签对齐排版、Markdown 行内样式、主题色、打印与导出。

无需安装、无需后端、离线可用——双击打开即可使用。

> A single-file, front-end only resume editor. Upload a PDF/Word resume and get an editable web page. No build, no backend, works offline.

---

## 特性

- **单文件 / 零依赖**：一个 HTML 文件包含全部样式与脚本，内联 `pdf.js`，离线可用。
- **上传即生成**：点「上传简历」或把 **PDF / Word(.docx)** 拖到页面，自动解析并套用模板生成可编辑简历。
- **所见即所得编辑**：点「编辑」后可直接修改任意文字，改完点「完成」，改动**自动保存**到本机浏览器。
- **板块（一级标题）**：新增、删除、**拖拽排序**；可为每个板块添加要点。
- **要点**：新增、删除、**拖拽排序**。
- **要点「标签」排版**：在要点里写 `标签：内容`（中/英冒号均可），同板块内按标签位置**自动对齐成列**；一行可写多个标签。
- **Markdown 行内标记**：`**加粗**`、`*斜体*`、`` `代码` ``、`==高亮==`、`~~删除线~~`，失焦自动渲染。
- **照片 / 主题色**：编辑模式可更换照片；工具栏取色器更换主题色。
- **打印 / 导出**：一键打印或导出 PDF（A4 排版）；导出**独立单文件 HTML**。
- **每份简历独立链接**：数据按地址栏里的 `#doc=…` 隔离，**多人 / 多标签同时使用互不覆盖**；【复制链接】保存或分享这份简历，【新建】开始一份全新的。
- **自动保存 / 重置**：随时恢复初始内容。

## 文件说明

| 文件 | 说明 |
| --- | --- |
| `index.html` | **简历生成器**：上传 PDF/Word 自动生成可编辑简历 |
| `resume.html` | 可直接编辑的示例简历（通用示例，非真人信息） |

## 使用

1. 双击打开 `index.html`（建议 Chrome / Edge）。
2. **生成**：点「上传简历」或拖入你的 PDF / Word(.docx)。
3. **编辑**：点「编辑」直接修改内容；板块/要点用 `⠿` 拖拽排序、`×` 删除，`＋ 要点` / `＋ 添加板块` 新增。
4. **排版**：在要点里写 `公司：XX　职位：XX　时间：XX`，自动对齐成列。
5. **保存 / 分享**：点「复制链接」保存这份简历的专属链接（数据按链接隔离，多人/多标签互不覆盖）；点「新建」开始一份新的。
6. **导出**：点「打印 / PDF」或「导出 HTML」。
7. 完整说明见页面内工具栏的 **`? 使用说明`**。

## 部署为在线版（可选）

仓库推到 GitHub 后，在 **Settings → Pages** 里选择分支的根目录，即可得到在线地址（如 `https://<user>.github.io/<repo>/`）。

## 兼容性

- 现代浏览器（Chrome / Edge / Firefox / Safari）。
- Word 仅支持 `.docx`；旧版 `.doc` 请另存为 `.docx` 或 PDF。
- 扫描件 / 图片型 PDF 无文字层，无法提取文字。
